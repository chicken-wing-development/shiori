# shiori markdown editor プライバシーに関する通知

対象: shiori markdown editor 1.0.0 Windowsデスクトップ版 / Web・PWA版 / 単一HTML版

発行元: テバ開発  
更新日: 2026年10月29日

shioriは、利用者が選択したMarkdownファイルと参照画像を端末内で読み取り、表示・編集します。文章、画像、下書きを開発者のサーバーへ送信する機能、アクセス解析、広告機能はありません。

編集中の1文書、その参照画像、表示設定（配色・表示モード・文字サイズ・見出しペインの幅）を端末のアプリまたはブラウザーの保存領域へ保存し、次回起動時に復元します。別の文書を開くと復元対象はその文書に置き換わります。旧版の保存データは自動削除せず、最後に開いていた文書を引き継ぎます。元のファイルと、保存ダイアログで書き出したファイルは利用者が管理します。アプリ内の保存領域を削除する場合はWindowsのアプリ管理またはブラウザーのサイトデータ設定を利用してください。削除前に必要な文書をファイルへ保存してください。

Windows版では、利用者が「開く」またはドラッグ＆ドロップで選択したMarkdownのフォルダー位置もアプリ専用領域に保持します。この場所を基準に参照画像を読み取り、再起動後に追加された相対パスも解決します。文書に記載された絶対パスや、選択フォルダー外へ出るパスを自動で読み取ることはありません。より広い範囲の画像を利用する場合は、利用者が「参照画像のフォルダー」を明示的に選択します。

外部画像の表示は初期状態では無効です。利用者が有効にすると画像配信元へ通信します。また、Windows版でHTMLまたはPDFへエクスポートすると、本文に含まれる外部画像URLの配信元へ通信します。名前解決したIPを検証して接続先を固定し、内部ネットワーク・端末内・特殊用途アドレスへの取得を拒否します。この取得ではプロキシ・Cookie・認証情報・リファラーを使用せず、リダイレクトを拒否します。Web / PWA / 単一HTML版のエクスポートでは外部URL画像を自動取得しません。配信元には通常の通信に伴うIPアドレスなどが伝わります。

Mermaidは外部通信を禁止した隔離環境で描画します。図内の画像ノードには対応しません。読み込んだSVGと生成したSVGからスクリプト・外部参照を除去します。

HTML・PDFへ出力する際は、参照画像とMermaidから生成したSVGを含む文書を端末内で作成します。通常のMarkdown保存では変換・埋め込みを行いません。保存したファイルを共有する相手と内容は利用者が選びます。外部リンクを選ぶと既定のブラウザーやメールアプリを開き、各サービスのプライバシーポリシーが適用されます。

Web / PWA版の読み込み・更新ではアプリの配信元と通信します。Microsoft Storeによる配布・更新とMicrosoft Edge WebView2 Runtimeの動作には、Microsoftの規約・プライバシー情報が適用されます。

この通知はアプリ内の「ヘルプ・アプリ情報 → プライバシー」からも確認できます。
