# Rust側の再構築

## 責務

| モジュール | 責務 |
| --- | --- |
| `filesystem.rs` | ファイル名・相対パス検証、開いたハンドルの実パス確認、サイズ制限付き読み取り、原子的保存 |
| `backend.rs` | 文書の基準フォルダー、失効可能な文書ID、画像の総量制限、使い切りの保存先チケット |
| `commands.rs` | Tauriのダイアログ・OSドロップイベント、非同期処理、現在の文書位置の保存・復元 |
| `pdf.rs` | 権限のない専用WebView、静的HTML専用プロトコル、画像読み込み待機、WebView2のPDFストリーム生成 |
| `remote_images.rs` | 外部画像URL・公開IPの検証、DNS結果を固定した取得、プロキシ・リダイレクト拒否、通信と容量の上限 |
| `lib.rs` | 状態とコマンド、ウィンドウイベントの登録 |

## 文書と画像

ネイティブの選択ダイアログまたはOSドロップイベントだけが実パスを受け取ります。RustはMarkdownをUTF-8・2 MiB以内で読み、基準フォルダーをランダムな文書IDに結び付けます。画面にはID・ファイル名・本文を返し、実パスを指定するIPCは公開しません。

参照画像の読み取りには文書IDとMarkdown内の参照を渡します。クエリー・フラグメントを取り除き、URLエンコードを1回だけ解釈します。区切り文字を統一してドット要素を解決し、絶対パス、UNC、デバイス名、ADS、制御文字、親への脱出を拒否します。

Windowsでは正規化したパスだけでなく、開いたファイルハンドルの最終パスも基準フォルダー内か照合します。検証後の読み取りには同じハンドルを使います。PNG/JPEG/GIF/WebP/AVIF/SVGのみ、1枚8 MiB、100個、合計32 MiBに制限します。SVGのサニタイズは表示とHTML・PDF出力の両方で実施します。

画面は文書の変更時に読み込み対象を更新し、古い文書の非同期結果を破棄します。HTML・PDF出力は開始時の本文と文書IDを保持し、必要な画像の読み込みが完了してから変換します。

外部画像のエクスポートには、メイン画面だけに許可した`fetch_export_image`を使います。URLの形式・認証情報・長さを検証し、名前解決した全アドレスが公開IPであることを確認します。そのアドレスをreqwestの`resolve_to_addrs`へ渡して接続先を固定し、DNSの再解決による内部ネットワークへの迂回を防ぎます。IPv4/IPv6のループバック・プライベート・リンクローカル・特殊用途・移行用アドレス、ローカル名を拒否します。プロキシ・リダイレクト・Cookie・認証情報・リファラーを使用せず、同時2件、名前解決を含め15秒、応答8 MiBに制限します。TLSの証明書検証は元のホスト名に対して実施します。

ブラウザーのFetch APIには検証済みの接続先IPを固定する手段がないため、Web/PWA/単一HTML版のエクスポートでは外部URL画像を取得しません。画像をローカルに保存して相対パスで参照するか、Windows版で出力する案内を表示します。CORSはリクエスト送信自体を止める仕組みとして使用しません。

取得経路に関係なく、ラスター画像は拡張子・Content-Typeと実データの形式を照合し、デコードに成功した場合だけ出力します。SVGは安全化した結果をデコードします。デコード後の寸法も検証し、32メガピクセルを超える画像を拒否します。出力するリンクの`//host/path`形式はHTTPSへ正規化します。

自動保存には文書IDと参照済み画像を含めます。Rustは受理された文書の基準フォルダーを`document-location.json`へ原子的に保存します。再起動時は記録されたIDとの一致を検証し、フロントエンドからフォルダーを書き換えることはできません。選択キャンセル時は元の文書を維持し、別の文書への切り替え時は古いIDを失効させます。

## 保存

保存ダイアログで選択されたパスを一度限りのチケットに結び付けます。本文の変換完了後にチケットを消費し、UTF-8サイズを検証して、保存先と同じフォルダーの一時ファイルに書き込み・同期・置換します。変換失敗、サイズ超過、書き込み失敗、置換失敗時は元ファイルを保持します。キャンセル・失敗したチケットは再利用できません。

Markdown保存は相対記法とMermaidのソースを維持します。単体で共有する文書はHTML・PDFへ出力します。HTMLは64 MiB、PDFは128 MiBまでとし、PDFのチケットにはテキストを書き込めません。生成に失敗しても保存先を変更しません。

PDF用のHTMLはランダムなウィンドウ名に紐づくメモリーへ一時的に保持します。専用プロトコルは同じウィンドウからの一致するパスだけへ応答します。固定CSPでスクリプト・外部通信・フレームを禁止し、Tauri capabilityはメイン画面だけに付与します。画像・フォントの読み込み完了後にWebView2のPrintToPdfStreamを呼び、COMオブジェクトはUIスレッド内で扱います。成功・失敗のいずれでも専用ウィンドウとHTMLを解放します。WebView2との型互換性を保つためTauriは2.12系列に固定しています。

## 確認範囲

相対画像、URLエンコード、日本語、参照形式、SVG、未保存確認、非同期読み込み中の保存、再起動復元、フォルダー外参照、ジャンクション、サイズ上限、保存失敗を回帰テストで確認します。結果と配布物は`VALIDATION.md`に記録します。
