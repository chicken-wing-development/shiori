# ヘルプ・アプリ情報と見出し幅の検証

実施日: 2026年10月29日。対象: shiori 1.0.0。

## 変更

- 「その他 → ヘルプ・アプリ情報」とF1から使い方を表示。右下のバージョンからアプリ情報を表示。
- ロゴ・バージョン・Copyright © 2026 テバ開発を表示。問い合わせ先は掲載しない。
- 同じダイアログの「アプリ情報」「プライバシー」「使い方」をマウスとキーボードで切り替え。本文をスクロールしても閉じるボタンは表示。
- 見出しペインの境界をドラッグ、左右キー、Home / Endで調整。幅を端末内に保存し、再起動時に復元。ダブルクリックで標準幅へ戻す。
- 保存済みの幅を検証し、狭い画面では編集領域を確保する範囲へ収める。ドラッグのキャンセル・フォーカス喪失時は変更前に戻す。
- プライバシー通知と単一HTML版の案内を実際の通信動作に合わせて更新。

Rustのコマンド・権限・エクスポート処理と依存関係には変更なし。

## 実WebView2と配布物

専用のWebView2プロファイルで、ビルドしたARM64版と配布フォルダー内の実行ファイルを操作した。アプリ情報・プライバシー・使い方の表示、矢印キーによるタブ切替、F1、見出し幅のドラッグ（215→396px）・右キー（406px）・再起動後の復元（406px）・ダブルクリックによる初期化（215px）を確認した。

x64の配布版でも起動・コピーライト画面・通常終了を確認した。x64はWindows 11 ARM64上のエミュレーションでの検証。検証用ウィンドウはすべて終了し、ユーザーが使用していた旧版には操作を行っていない。文書位置情報のファイルは検証前後のSHA-256が一致した。記録: `native-smoke-results.json`。

配布先: `releases/v1.0.0/windows-app-info/`。

- `shiori-1.0.0-arm64.zip`: 5,391,452 bytes
- `shiori-1.0.0-x64.zip`: 5,496,202 bytes
- 各CPU向けの未署名開発用MSIXも生成。

ZIP / MSIXのSHA-256、内蔵exeとビルド結果の一致、CPU種別、第三者ライセンス同梱、検証専用コードが製品に含まれないことを確認した。記録: `distribution-verification.json`。パッケージを検証し直す場合は次を実行する。

```sh
python tests/native/verify-packages.py --release-directory releases/v1.0.0/windows-app-info --output test-results/app-info-outline/distribution-verification.json
```

Microsoft Storeへの提出・公開は行っていない。
